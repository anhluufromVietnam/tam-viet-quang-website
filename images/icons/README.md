# Icons

Icons cho các ngành nghề hoạt động.

## 📋 Files cần có

- `tech-icon.png` - Technology & Software
- `ai-icon.png` - AI Platform / VyIQ
- `robotics-icon.png` - Robotics & Hardware
- `education-icon.png` - Education & EdTech
- `media-icon.png` - Media & Events
- `travel-icon.png` - Travel & Tourism

## 🎨 Guidelines

### Kích thước
- 128x128px (standard)
- 256x256px (retina)

### Style
- Flat design hoặc line art
- Màu sắc: Brand colors (#4B4ACB, #4CAF75)
- Nền trong suốt (transparent PNG)

### Nội dung
- Đơn giản, dễ nhận diện
- Tránh quá nhiều chi tiết
- Nhất quán về style

## 📐 Kỹ thuật

- Định dạng: PNG (transparent)
- Color space: sRGB
- File size: < 20KB mỗi icon
