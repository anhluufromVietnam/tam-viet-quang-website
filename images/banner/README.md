# Banner Images

Hình ảnh banner cho các section chính của website.

## 📋 Files cần có

- `hero-illustration.png` - Hình minh họa hero section (800x600px)
- `about-image.png` - Hình ảnh giới thiệu công ty (800x600px)

## 🎨 Nội dung khuyến nghị

### hero-illustration.png
- Chủ đề: AI + Robotics + Technology
- Có thể là: illustration, 3D render, hoặc photo
- Phong cách: Modern, tech, futuristic

### about-image.png
- Chủ đề: Văn phòng, team, hoặc sản phẩm
- Có thể là: photo thực tế hoặc illustration
- Phong cách: Professional, clean

## 📐 Kỹ thuật

- Định dạng: PNG hoặc JPG
- Resolution: 72dpi (web) hoặc 300dpi (print)
- Color space: sRGB
- File size: < 500KB (sau khi nén)
