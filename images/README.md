# 📁 Hướng dẫn sử dụng thư mục Images

Thư mục này chứa tất cả hình ảnh cho website Tâm Việt Quang.

## 📂 Cấu trúc thư mục

```
images/
├── logo/           # Logo công ty
├── banner/         # Hình ảnh banner, hero section
├── products/       # Hình ảnh sản phẩm
├── team/           # Hình ảnh đội ngũ
├── icons/          # Icons cho các ngành
└── README.md       # File này
```

## 🖼️ Danh sách ảnh cần chuẩn bị

### Logo (`images/logo/`)
- `logo.png` - Logo chính của Tâm Việt Quang
  - Kích thước: 512x512px (vuông) hoặc 1024x512px (ngang)
  - Định dạng: PNG với nền trong suốt
  - Màu sắc: Xanh tím (#4B4ACB) + Xanh lá (#4CAF75)

### Banner (`images/banner/`)
- `hero-illustration.png` - Hình minh họa cho hero section
  - Kích thước: 800x600px
  - Nội dung: AI + Robotics + Technology
  
- `about-image.png` - Hình ảnh về công ty
  - Kích thước: 800x600px
  - Nội dung: Văn phòng, đội ngũ, hoặc sản phẩm

### Products (`images/products/`)
- `vyiq-platform.png` - VyIQ Platform
- `ai-chatbot.png` - AI Chatbot
- `robot.png` - AI Robot
- `iot-solution.png` - IoT Solutions

Kích thước khuyến nghị: 800x600px

### Icons (`images/icons/`)

## 🎨 Brand Colors

Sử dụng các màu sau cho các thiết kế:

```css
Primary Blue:   #4B4ACB
Primary Green:  #4CAF75
Black:          #111111
White:          #FFFFFF
```

## 📝 Lưu ý

1. **Tối ưu ảnh**: Nén ảnh trước khi upload để giảm dung lượng
2. **Định dạng**: 
   - PNG cho logo, icons (cần nền trong suốt)
   - JPG cho photos, banners
3. **Tên file**: Sử dụng chữ thường, gạch nối, không dấu
4. **Backup**: Giữ bản gốc ảnh chất lượng cao

## 🔧 Công cụ tối ưu ảnh

- [TinyPNG](https://tinypng.com/) - Nén PNG/JPG
- [Squoosh](https://squoosh.app/) - Tối ưu ảnh online
- [ImageOptim](https://imageoptim.com/) - Tối ưu ảnh cho Mac
