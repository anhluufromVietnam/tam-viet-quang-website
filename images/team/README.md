# Team Photos

Hình ảnh đội ngũ lãnh đạo và nhân sự.

## 📋 Files cần có

- `team-1.jpg` - Thành viên 1
- `team-2.jpg` - Thành viên 2
- `team-3.jpg` - Thành viên 3
- ...

## 🎨 Guidelines

### Kích thước
- 400x400px (vuông)
- Hoặc 800x800px cho retina

### Nội dung
- Portrait photo (chụp chân dung)
- Background đơn giản, nhất quán
- Ánh sáng tốt, rõ mặt

### Phong cách
- Professional
- Friendly, approachable
- Nhất quán về style

## 📐 Kỹ thuật

- Định dạng: JPG
- Background: Trắng, xám nhạt, hoặc blur
- File size: < 150KB mỗi ảnh
