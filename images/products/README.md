## 🎨 Guidelines

### Kích thước
- 800x600px (4:3 ratio)
- Hoặc 1200x900px cho retina displays

### Nội dung
- Screenshot sản phẩm, hoặc
- Product mockup, hoặc
- Illustration minh họa

### Phong cách
- Clean, professional
- Nhất quán về màu sắc và style
- Có thể thêm gradient background

## 📐 Kỹ thuật

- Định dạng: PNG hoặc JPG
- Background: Solid color hoặc gradient
- File size: < 300KB mỗi ảnh
